Exam Proctor SaaS

An online exam platform that many colleges can share, where each college sees only its own exams, students and results.

  • Java 21
  • Spring Boot
  • Spring Security
  • JWT
  • WebSockets
  • PostgreSQL
  • Docker
  • Multi-tenant setup where every request is checked against the college stored in the user's login token, so no college can see another's data.
  • Live proctoring: tab switches, copy/paste and right-clicks during an exam show up on the admin's dashboard instantly over WebSockets.
  • Three roles (Super Admin, College Admin, Student), auto-graded MCQs, and a background job that closes exams on time and flags late submissions.
